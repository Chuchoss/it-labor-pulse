# ADR 014. Официальные дневные FX и ссылки источников

## Context

Phase 1 хранит зарплатный канон в RUB/net, но статический USD fallback не
подходит для production и не позволяет корректно показать исторический снимок
в выбранной валюте. Карточке вакансии также нужна официальная ссылка без
HH-специфичного поля в общей модели.

Банк России документирует XML endpoint
[`XML_daily.asp`](https://www.cbr.ru/development/SXML/): `date_req` имеет формат
`dd/mm/yyyy`, отсутствие параметра возвращает последнюю зарегистрированную
дату. Ответ содержит дату набора, `CharCode`, `Nominal` и `Value`.

## Decision

- Provider `cbr` получает только официальный XML
  `https://www.cbr.ru/scripts/XML_daily.asp`; это дневной справочный курс, не
  intraday/realtime и не платёжный курс.
- В PostgreSQL хранится `rub_per_unit = Value / Nominal`; `Nominal` никогда не
  предполагается равным единице.
- Нормализация вакансии использует дату публикации и ближайший предыдущий курс
  не старше 7 календарных дней. Текущие карточки/рейтинги используют последний
  доступный курс; исторические points — курс на дату point с тем же bounded
  fallback.
- Канонические суммы RUB/net не переписываются при смене валюты отображения.
  При отсутствии курса raw salary сохраняется, canonical salary остаётся
  недоступной и исключается из salary aggregates.
- UI поддерживает RUB, USD, EUR, CNY, KZT, AMD и сообщает «Курс ЦБ на DATE».
- `vacancies.source_url` — nullable source-neutral URL. Adapter принимает
  только абсолютный HTTP(S) URL без userinfo/control chars и применяет policy
  доменов источника. Для существующих HH строк разрешён server-side backfill
  `https://hh.ru/vacancy/{external_id}` только при строго числовом ID.

## Consequences

- (+) Воспроизводимые исторические конверсии и явная provenance.
- (+) Новый FX/job provider добавляется адаптером, BFF не вызывает внешний API.
- (+) Browser не конструирует и не доверяет произвольным source URL.
- (−) До успешного sync часть non-RUB salary остаётся без canonical суммы.
- (−) Дневной курс ЦБ не отражает внутридневное движение и не является
  финансовой рекомендацией или курсом платежа.
